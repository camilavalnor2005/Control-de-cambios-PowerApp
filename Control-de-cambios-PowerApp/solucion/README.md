# Archivo de la aplicación

En esta carpeta va el archivo exportado de la aplicación, para poder abrirla o instalarla en otro entorno de Power Apps.

## Cómo exportar la aplicación

**Opción 1 · Solo la app (.msapp)**

1. Abrir la aplicación en Power Apps Studio.
2. Elegir **Guardar como › Este equipo** (*Save as › This computer*). En algunas versiones aparece como **Descargar una copia** (*Download a copy*).
3. Subir el archivo `.msapp` a esta carpeta.

**Opción 2 · App y flujo juntos (.zip)**

Si la aplicación y el flujo están dentro de una solución de Power Apps:

1. Ir a **Soluciones** en [make.powerapps.com](https://make.powerapps.com).
2. Seleccionar la solución y elegir **Exportar**.
3. Subir el archivo `.zip` a esta carpeta.

## Cómo importarla en otro entorno

- **Archivo .msapp:** en Power Apps Studio, elegir **Abrir › Examinar** y seleccionar el archivo. Después, volver a conectar la lista de SharePoint.
- **Archivo .zip:** en **Soluciones**, elegir **Importar solución** y seleccionar el archivo.

> **Importante:** este repositorio es público. Antes de subir el archivo, revisen que no incluya información interna de la empresa.
